# Genie fleet-manager toolset (from pickuphere.md)
Inspect engines/logs; control workers (pause/resume/readmit/recover/enroll); run recipes
(clone/build/pull/download/launch/stop); prepare/observe Hourglass; add/remove routes;
checkpoint/revert; report. Conversational approval only.

## Partial delivery — 24 September 2026

Actual Genie tools now cover enrolled source/configuration inspection, owned
drain/resume, detached fleet power, persistent admission/serving-check receipts,
and [bounded native recipe trials](../../docs/genie-recipe-trials.md). Native
checks distinguish gateway generation, tool-result exchange and real cache reuse.
Trial restoration checks original artifacts plus the exercised serving
boundaries before releasing its own maintenance hold. General engine enrollment,
arbitrary command execution and a universal recipe/Hourglass loop are not implied.
