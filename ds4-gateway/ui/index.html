How to read these numbers

Decode includes reasoning tokens. Large numbers are the last reported chunk speed; request averages sit underneath. Idle devices keep their last measurement, clearly dated—not a claim of current throughput. Prefill counts only newly processed tokens, not the cached prefix.

Cold starts mean zero prefix tokens reused. A resident miss can still lead to a successful disk restore. Cache counts are observed events since the displayed time (up to 15 minutes of initial log history), not a lifetime hit rate. “Prefix reuse” alone does not prove which storage tier supplied it. Gateway errors and client cancellations are kept distinct.

Debug snapshots contain operational metadata and hashed session identifiers, never prompts, images, tool arguments or answers. Review before sharing. Existing gateway logs remain untouched.

Requested thinking shows the client's fields, not the engine's effective level. Hover the value for its source fields. THINKING in a worker's status badge is its current generation phase. Idle workers show the last request; queued requests are not inspected until dispatched.
